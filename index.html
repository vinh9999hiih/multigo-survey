Đồng Bộ Với Google Sheets

Tự động lưu câu trả lời vào Google Sheet cá nhân

Bạn có thể gắn đường link Google Apps Script Web App để mỗi khi có người làm khảo sát trên GitHub Pages, dữ liệu sẽ tự động đẩy về Google Sheet của bạn.

Hướng dẫn tạo Webhook:
Mở Google Sheet -> Tiện ích mở rộng (Extensions) -> Apps Script -> Dán mã từ file google-apps-script.js -> Triển khai (Deploy) làm Web App với quyền truy cập "Anyone".
